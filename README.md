# java-lotto-precourse
## 📌 기능 요구 사항

### 1. 입력 기능
-  구입 금액 입력받기
-  1,000원 단위인지 검증
-  숫자 외 입력 예외 처리
-  당첨 번호 입력받기
-  중복 없는 6개 숫자 검증
-  쉼표 기준 파싱
-  범위 1~45 검증
-  보너스 번호 입력받기
-  당첨 번호와 중복 금지
-  범위 1~45 검증

### 2. 로또 발행
-  입력 금액만큼 로또 수량 계산
-  랜덤 로또 번호 생성 (6개, 오름차순, 중복 없음)

### 3. 당첨 결과 계산
-  당첨 번호와 일치 개수 계산
-  보너스 번호 일치 여부 판단
-  등수 판정
-  상금 누적

### 4. 출력
-  구매 로또 출력 (정렬)
-  당첨 통계 출력
-  수익률 출력 (소수 둘째 자리 반올림)

### 5. 예외 처리
-  IllegalArgumentException 사용
-  `[ERROR]` prefix 출력
-  잘못된 입력 시 재입력 요구
